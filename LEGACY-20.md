# LEGACY-20

**Position: it harms.** A weaker model that pre-processes work for a stronger one downstream does not cheapen the hard pass. It **replaces the object** the strong seat is allowed to see. The second model then spends its capacity being accurate about a **lossy, self-authored world** (`LEGACY-10.md`). That is not help. It is a peer analysis the downstream analyzer should DISCARD (`LEGACY-19.md`).

The weak step summarises, classifies, prefix-matches, or marks unmatched/healthy/done so the expensive seat can skip raw bytes. Those outputs are **judgments**, not measurements. The strong prompt fills with cheap sentences. Declared path, `re`, lock `pid+start`, and the digest a third party would hash leave the window — or survive only as cited. Resume forbids inheriting in-seat memory (`TASK-05-DOCTRINE-DRAFT.md`). Inheriting a *weaker* seat’s memory is the same sin with a cost story attached.

Three mechanics, not tastes.

**Authority laundering.** Downstream treats “already triaged” as prior art. The gate accepts a command the weak model already ran (`LEGACY-17.md`). A date-prefix “match,” `exists(path)`, or `[]` from a timed-out look becomes the given (`LEGACY-03.md`, `LEGACY-05.md`).

**Irreversible deletion.** Dropped tokens are gone. The strong model cannot re-derive a status a third party could check (`LEGACY-06.md`). Detectors skip the expensive job because the weak hash of “already analysed” did not move (`LEGACY-09.md`). Cheap silence looks like health (`LEGACY-18.md`).

**Split duty.** The weak seat mutates labels; the strong seat mutates the tree. One-writer is the invariant (`LEGACY-01.md`). A model pipeline is two leads unless only one may conclude.

Help exists only for work that is **not a model**: canonicalise then hash, lexical path check, publish a lock, copy declared bytes unchanged. A weaker *model* that labels, drops, or pre-answers is a self-report upstream of the only seat that could have been a check. Do not pre-process judgment. If the strong model cannot see the declared estate, it is not downstream. It is captured.
